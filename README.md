# 山西 Shanxi

黄土为底、晋式琉璃绿为印、青砖与老陈醋褐点缀的浅色主题。壁纸：王家大院、平遥古城、大同古建、五台山、南禅寺、晋祠、雁门关、广胜寺飞虹塔。

![preview](preview.png)

## 安装

```bash
omarchy theme install https://github.com/rwanglq-ctrl/omarchy-shanxi-theme
```
