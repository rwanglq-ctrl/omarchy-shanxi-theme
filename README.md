# 山西 Shanxi

黄土为底、晋式琉璃绿为印、青砖与老陈醋褐点缀的浅色主题。壁纸：悬空寺、应县木塔、壶口瀑布、云冈石窟、晋祠、晋剧。

![preview](preview.png)

## 安装

```bash
omarchy theme install https://github.com/rwanglq-ctrl/omarchy-shanxi-theme
```
